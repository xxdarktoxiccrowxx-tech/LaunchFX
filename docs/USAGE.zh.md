# 安装与使用

## 第一次打开

macOS 将 LaunchFX 拖入「应用程序」。Windows 使用安装程序，或解压便携 ZIP 后运行 LaunchFX.exe。建议先完成安装再创建目标应用快捷方式，以免移动 LaunchFX 后快捷方式失效。

进入「设置 → 应用与入口」，检查检测到的路径。默认寻找常见安装目录；Windows 还会查询匹配的 Microsoft Store 应用。自动检测不成功时手动选择 `.app` 或 `.exe`。

「自动识别」适合大部分安装。「直接打开应用」只打开所选程序。「统一版模式链接」适用于支持 `codex://new?mode=chat` 和 `codex://new?mode=codex` 的统一版客户端；此路由由目标客户端提供，未来可能变化。独立 ChatGPT 应用请使用自动或直接打开。

Windows 仅在所选程序的协议注册或 Store 清单能够证明它支持统一版时，才会自动复用客户端并切换模式。无法自动识别时，请为 Codex 配置选择实际客户端 `.exe`，再选择「统一版模式链接」；独立应用使用「直接打开应用」。

## 动画与全屏独立

顶部选择 ChatGPT 或 Codex，然后设置右侧面板。两个应用分别保存配置。

- 关闭「启动特效」：立即启动目标应用，仍按全屏开关设置窗口模式。
- 打开「启动后全屏」：macOS 进入原生全屏；Windows 进入无边框全屏。
- 关闭「启动后全屏」：请求普通窗口。Windows 会恢复由 LaunchFX 保存的尺寸与边框。
- 「随机播放」优先从收藏中选择；收藏为空时使用全部 12 种动画。

Codex 默认开启全屏。已打开应用时仍可通过 LaunchFX 改变窗口模式；可选择跳过动画。

## 日常启动入口

在目标面板或设置中创建快捷方式：

- macOS：桌面出现 `ChatGPT — LaunchFX.app` / `Codex — LaunchFX.app`，拖到 Dock。
- Windows：桌面出现对应 `.lnk`，可由你固定到开始菜单 / 任务栏。固定方式由 Windows 版本决定。
- 托盘 / 菜单栏也可以直接启动两个目标应用。
- 开启全局快捷键后：`⌘/Ctrl + Alt + 1` 启动 ChatGPT，`⌘/Ctrl + Alt + 2` 启动 Codex。

不要直接点击原应用图标来期待播放特效；原图标不会经过 LaunchFX。关闭 LaunchFX 窗口默认保留托盘运行，可从托盘菜单退出。登录启动默认关闭，开启后只静默启动 LaunchFX。

## 黑洞吸入真实桌面

先选「黑洞奇点」，再在「设置 → 沉浸感」开启「把真实桌面卷入特效」。macOS 需手动给予屏幕录制权限。LaunchFX 在播放前获取屏幕缩略图，选出指定显示器的一帧作为临时纹理，其余缩略图丢弃。动画完成后释放画面，不写入文件、不上传。预览永远使用虚拟画面。

未授权或读取失败时，仍播放合成动画。屏幕录制与辅助功能是不同权限：前者控制画面来源，后者控制目标窗口模式。

## 性能、音效与取消

默认使用自动平衡、60 FPS 上限。电池模式可选择节能 / 30 FPS；高刷新屏可选 120 FPS 上限，实际帧率受设备与画面大小影响。减少动态效果会使用静态主体与柔和淡入淡出，始终保留你选择的播放时长；不会把 4 秒或 10 秒改成更短的固定时间。系统开启减少动态效果时，时长滑块旁会显示提示。启动或预览期间，工坊背景画面会暂停，结束后恢复，以减少显卡负担。

音效在本地合成，默认关闭；安全预览不播放声音。音量独立控制。

实际动画中按 Esc 会跳过特效并继续打开应用。点击 × 会取消启动。预览中 Esc 和 × 都只是关闭预览。动画结束并进入「正在打开」后，目标应用可能已启动。

## 配置与故障恢复

设置会自动保存。若保存失败，顶部会显示「尚未保存」和「重试保存」，启动与预览会暂停，避免使用旧配置；点击重试或再次修改设置会重新保存尚未完成的改动。

配置在系统的 LaunchFX 应用数据目录中；「打开数据目录」可直接查看。JSON 导入会验证字段，且不会自动启用登录启动、全局快捷键或新的桌面访问。不同电脑上的应用路径可能需要重新选择。

损坏配置会备份后回退到默认值；恢复默认前也会备份。日志仅记录有限的启动 / 错误信息，不保存截图、聊天内容或账户信息。

常见情况：

| 现象 | 检查 |
| --- | --- |
| 没有动画 | 是否通过 LaunchFX 入口启动；特效是否开启；是否设置运行时跳过 |
| 没有全屏 | macOS 辅助功能权限；Windows 目标程序是否以更高权限运行 |
| 显示找不到应用 | 手动选择实际安装路径；重新检查独立版 / 统一版模式 |
| 没有真实桌面 | 桌面转场开关；屏幕录制权限；授权后重启 LaunchFX |
| 动画掉帧 | 改为节能或 30 FPS；关闭其他占用 GPU 的程序 |
| 快捷键不可用 | 其他程序可能占用了该组合；可使用托盘 / 桌面入口 |

卸载前可关闭登录启动与全局快捷键，然后退出 LaunchFX，删除程序和自行创建的快捷方式。设置文件可保留以便重装，也可由你通过数据目录删除。
