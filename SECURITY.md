# Security

Please report vulnerabilities privately through the repository's security advisory feature when enabled. Do not include credentials or private screenshots in public issues.

The security boundary includes local-only renderer content, sandboxed windows, narrow IPC methods, sender validation, validated app paths, structured helper inputs and target-specific window control. Screen access and system integrations must remain opt-in.

Builds should use maintained Electron releases and receive dependency review before distribution. Sign releases with the maintainer's own identity; no signing credentials belong in this repository.
